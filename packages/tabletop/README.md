# @netnetcapital/tabletop

The client kit the board-style Net Forge templates share (tower defense,
idle, card battler, monster collector): the room connection and input clock
for rules genres, the styled 3D stage, the store, stake and gear wiring, and
the HUD shell. Used by `@netnetcapital/template-*` clients; see
`@netnetcapital/kit-play` to run one on your own computer.
