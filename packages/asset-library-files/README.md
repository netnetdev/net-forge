# @netforge/asset-library-files

The built asset library of the Net Forge engine: optimized models, sprites,
textures and sounds addressed by library id (`style.lowpoly.truck`), with
`library/index.json` mapping ids to files. `kit play`
(`@netforge/kit-play`) serves it to a game running on your own
computer.

Every file is third-party art released under CC0 1.0 (Quaternius, Kenney,
Screaming Brain Studios, cynicmusic); NOTICE lists every pack and where its
license was verified.
